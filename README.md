# Silicon AI

A premium AI chat app for Android with **real-time streaming replies** and **photo and document scanning**.

[**Get it on Google Play**](https://play.google.com/store/apps/details?id=com.lexcore.silicon_ai)

> **Showcase repository.** This repo presents a live product we built. The application source code is private.

## Features
- Streaming chat: answers appear word by word, as they are generated.
- Scan a photo or document and ask questions about it.
- Conversation history on the device.
- Google Sign-In.
- Monthly Pro subscription.

## Built with
Flutter · Dart · streaming API · subscriptions
